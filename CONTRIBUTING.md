# How to Contribute

We'd love to accept your patches and contributions to this project!

## Contribution Guidelines

1. **Sign the Contributor License Agreement (CLA):**
   Only original source code submitted by the author can be accepted. Before we can accept your pull requests, you must sign the Google Contributor License Agreement: https://cla.developers.google.com/

2. **Code Reviews:**
   All submissions, including submissions by project members, require review. We use GitHub pull requests for this purpose. Consult GitHub Help for more information on using pull requests.

3. **Community Guidelines:**
   This project follows the [Google Open Source Community Guidelines](https://opensource.google/conduct/).
